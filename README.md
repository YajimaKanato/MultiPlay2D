# ビリヤード × ターンドラフト
### コンセプト
# ”全員で盤面を作り出すビリヤード”
# 1. ゲーム概要
## 世界観

ここは悪魔を使役する魔術師が集う世界「マジカルワールド」。
魔術師はショットの直前にスクロール（魔法書）を展開し、そのターンだけ有効な悪魔の力（＝効果）を召喚して盤面へ干渉する。

悪魔はキャラクターとして台に立つのではなく、
選択した効果の具現化として魔法陣から現れ、ボールやポケットに影響を与える存在。

# 3. コアコンセプト
### ”全員が盤面を狂わせる、悪魔的ビリヤード”

ショット担当は 強化効果 を選び、自分のショットを有利にする

他プレイヤーは 妨害効果 を選び、盤面を混乱させる

腕前だけでなく、効果選択・盤面操作・読み合いが毎ターン発生

他人のターンが待ち時間にならず、全員が常に盤面へ介入し続けることができる

# 4. ゲームシステム
## ターンの流れ
### 1.ショット担当を決定→ショット担当が強化効果を選択

### ※同時に他プレイヤーが妨害効果を選択

### 2.選ばれた効果を盤面へ反映

### 3.ショットを行う

### 4.効果を解除し、次のプレイヤーへ交代

## 効果の扱い
効果は「悪魔の力」としてスクロールから具現化

そのターンのみ有効

ターン終了後に解除される

# 5. 遊びとして実現したいこと（コア部分・売り）
他人のターンにも参加できる
妨害効果の選択で常に盤面へ介入

実質的に待ち時間がない(超エキサイティングな体験を提供できる）

毎ターン盤面が変化する読み合い
壁・爆弾などの妨害で配置が激変

ショット担当は強化効果で勝利を狙う

事故と逆転が生まれるパーティー性
妨害がショット担当に利用されることも！？

想定外の盤面が生まれ、観戦も盛り上がる

技術差を効果選択で緩和
初心者でも強化効果で狙いやすい

上級者は妨害を読み切る戦略性が問われる

# 8. まとめ
## 本作は 「ビリヤード × ターンドラフト」 を軸に、魔術師が悪魔の力を使って盤面を操作するという世界観で、全員が常に影響を与え続ける”新しい”ビリヤード体験を提供するゲーム。
